# Architecture Decision Records (ADRs)

ADRs document *why* a significant technical choice was made.
They are written **before** implementation and are never deleted — only superseded.

## File naming

`NNN-short-title.md` — e.g. `001-database-orm.md`

## Template

```markdown
# ADR NNN: [Title]

**Date**: YYYY-MM-DD
**Status**: PROPOSED | ACCEPTED | SUPERSEDED by ADR-NNN

## Context

What situation or constraint forced a decision?

## Decision

What did we decide?

## Consequences

What is now easier? What is now harder? What risks does this introduce?
```
